# Frontend Mobile and Web

This directory contains the ThesisFormat frontend deliverables.

## Structure

- `Mobile-App/` — Flutter application for Android, iOS, Windows, macOS, Linux, and web.
- `Web-Dashboard/` — reserved for the web dashboard frontend.

## Mobile app setup

From `Mobile-App/`, run:

```bash
flutter pub get
flutter run
```

See `Mobile-App/README.md` and `Mobile-App/API_CONTRACT_FRONTEND.md` for app and API integration details.
